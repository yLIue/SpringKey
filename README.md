SpringKey 是一款桌面密码管理器，它支持多用户，帮助用户解决密码存储问题。

当前阶段：开发中

## 🌟 功能特点

- **加密存储**：AES-GCM-128，每个文件独立加密
- **多用户**：依据不同密钥进入不同的密码库
- **分组**：支持存放不同的分组
- **导入导出**：支持一键导入导出
- **自动备份**：定时间隔备份，随时可以恢复到某个快照
- **密码历史**：显示你的密码历史，支持快速填充
- **额外信息**：支持记录当前key的绑定信息，如手机邮箱，支持自定义
